# Changelog

All notable changes to `ice-identifiability` and to the accompanying paper.
Version numbers follow the manuscript revision, not semantic versioning: the
tool is v0.1.0 throughout, and the paper revisions are r12 and r13.

## r13

### Changed

* **G8 tests the channel's own raw sigma.** The gate compared the declared
  *thickness* uncertainty with the nuisance floor, which is the right operand
  only on the declared-posterior channel. On a freeboard channel the raw term
  is `kappa * sigma_freeboard`, so the gate was guarding a quantity that does
  not enter `alpha`: the freeboard run of the CCI file was cleared at 0.884
  (the posterior channel's ratio) while its own ratio is 0.12-0.24. G8 now
  divides `comps["a"]` — the raw term actually used — by `sigma_floor`.
* **G8 is evaluated per latitude band, worst band decides.** `K = b^2+c^2+d^2`
  grows with the local thickness and snow depth (median `sqrt(K)` spans
  0.411-0.853 m on the CCI file), so a domain-median ratio mixes fourfold
  different denominators. The bands are the ones the `alpha` table reports on.
  Each band's ratio is now written to `gates.json` (`bands[*].g8_ratio_median`)
  and to `gates[*].inputs.ratio_by_band`.
* **Verdict precedence: a missing declaration outranks a statistic that could
  not be formed.** A `not_assessable` G1/G2 now yields `INPUT_NOT_ASSESSABLE`
  ahead of a `not_assessable` G3. Consequence: PIOMAS is refused because it
  declares no thickness uncertainty, not because its grid cannot realise a
  square block. New reason code `G8_NOT_ASSESSABLE` for a floor ratio that
  cannot be evaluated on any cell; previously such a run fell through to
  `assessable`.
* **Freeboard fixture declares the same thickness error as the posterior
  fixture.** `synth_sigma_grid` sets `sigma_freeboard = sigma_thickness / kappa
  = 0.1025 m`, so S1 and S2 must return the same `alpha` (they agree to 2e-8).
  The previous value, 0.06 m, fails the corrected gate in the 70-80N band; the
  refusal path is covered by the CCI freeboard channel instead.
* Packaging: `pyproject.toml` package finder and `testpaths`/`pythonpath`
  pointed at `src/` while the sources are in `src_toolkit/src/`, so
  `pip install -e .` aborted and `pytest` collected nothing. Corrected;
  `pytest -q` from the archive root now collects and passes 29 tests with no
  `PYTHONPATH`.
* `REPRO_CHECK.txt` rewritten against this tree. The previous file described a
  different package (10 tests, 22 pages, `tools/`, `run_all.ps1`).
* Summary tables are now generated: `examples/make_summary_tables.py` writes
  `out/gate_matrix.csv`, `out/gate_values.csv` and `out/run_summary.csv` from
  the per-run records.
* Figure 4 (validation) is now generated by
  `examples/make_validation_figure.py` from the shipped truth and the two
  fixture runs.

### Removed

* `RULE_CHANGE.md`, `DOC_CODE_AUDIT.md`, `VERDICT.md`, `SPEC.md`: internal
  working notes, in Chinese, which disclosed the review process and cited
  review issue numbers. Their content is either in the paper or here.
* `orig/gates.py` (a pre-revision copy of a source file), `references_check.csv`,
  `manuscript.pdf` (byte-identical to `paper.pdf`), the LaTeX build artefacts,
  the raster duplicates of the vector figures, and the orphan `fig4_maps.pdf`.
* The claim of an "independent misuse ratio" of 96.10 for ATL20: it was
  `sqrt(9189)` taken from a slightly different median, so it confirmed nothing.

### Fixed

* `report.py` referred to `SPEC.md §7`, which no longer ships.
* `README.md` referred to `SPEC.md`, `VERDICT.md` and to a test command that
  collected nothing.

## r12

Initial public revision: nine gates, four verdicts, five exit codes, the
refusal-semantics precedence rule, four fixtures, and the report of the first
two defects (a `numpy.bool_` that destroyed a completed verdict, and a missing
block statistic read as a failed signal test).
